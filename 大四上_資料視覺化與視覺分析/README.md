# Data Visualization Projects

This folder contains various data visualization projects using D3.js.

## HW1: Scatter Plot
Implemented an interactive scatter plot to visualize the Iris dataset with customizable axes and flower class differentiation.

## HW2: Parallel Coordinate Plots
Created a parallel coordinate plot for the Iris dataset, allowing axis reordering and flower class visualization with poly-lines.

## HW3: Correlation Matrix
Developed three correlation matrices for male, female, and infant abalone data, highlighting attribute correlations with interactive design elements.

## HW4: Brushable Scatter Plot Matrix
Built an interactive 4x4 scatter plot matrix for the Iris dataset, with brushing functionality to highlight selected data points across plots.

## HW5: Stacked Bar Charts
Designed stacked bar charts to represent World University Rankings, showcasing multiple categorical data attributes.

## HW6: ThemeRiver
Crafted a themeriver to visualize house property sales, representing time series data with changing themes.

## HW7: Horizon Chart
Created a horizon chart to represent air pollution data, enabling efficient display of large time series data.

## HW8: Sankey Diagram
Developed an interactive Sankey Diagram to visualize relationships between categorical attributes in car evaluation data, with draggable nodes and tooltips.

## HW9: Spotify Tracks Data Visualization
Explored and visualized hidden patterns in Spotify Tracks data, analyzing key factors influencing track characteristics.

## Final Project: World’s Happiest Countries
Visualized the world's happiest countries and uncovered significant facts related to happiness scores.
