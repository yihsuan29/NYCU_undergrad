# Data Mining Lab Assignments

## Lab Assignment #1: Frequent Itemset Mining
- **Objective**: Implement and compare Apriori algorithm with non-Apriori methods for mining frequent and closed itemsets from synthetic datasets.
- **Method**: Use synthetic data generation, Apriori algorithm for mining frequent itemsets, and non-Apriori methods for efficiency improvement.

## Lab Assignment #2: Classification Model for Patient Survivability
- **Objective**: Build a classification model to predict patient survivability using medical data.
- **Method**: Train classification models with KFold cross-validation and analyze feature importance using tools like scikit-learn and SHAP.

## Final Project: Realized Volatility Prediction
- **Objective**: Predict realized volatility in financial markets based on historical price data.
- **Method**: Ensemble model combining LightGBM, FFNN, and TabNet for improved prediction accuracy.
