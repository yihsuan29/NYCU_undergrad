# Reinforcement Learning Labs

## Lab 1: Temporal Difference Learning
- Apply Temporal Difference learning on the 2048 game using an 𝑛-tuple network.

## Lab 2: Deep Q-Network (DQN)
- Implement Deep Q-Network to solve the MsPacman-v5 environment.

## Lab 3: Proximal Policy Optimization (PPO)
- Use Proximal Policy Optimization (PPO) to solve the Enduro-v5 environment.

## Lab 4: Twin Delayed DDPG (TD3)
- Implement Twin Delayed DDPG (TD3) to solve the CarRacing-v2 environment.

## Final Project: Racecar Control
- Train a neural network to control a racecar using reinforcement learning algorithms.
