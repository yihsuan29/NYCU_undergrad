## Artificial Intelligence

### HW1: Image Classification & Object Detection  
- Train traditional ML models for image classification.  
- Apply a pretrained YOLOv7 model for object detection and finetune it to achieve >90% accuracy.  

### HW2: Sentiment Classification & Language Modeling  
- Implement a Bi-Gram language model and an RNN-based text classifier.  
- Apply the SOTA method, DistilBERT for sentiment analysis.  

### HW3: AI for Pac-Man (Search & RL)  
- Implement minimax and expectimax search for Pac-Man AI.  
- Develop a basic reinforcement learning model using Q-learning.  
- Compare performance with deep reinforcement learning (DQN).  

### HW4: Explainable AI & Adversarial NLP Attacks  
- Explore explainable AI techniques and adversarial attacks in NLP.  
- Visualize attention weights using exBERT.
- Apply LIME to explain models trained for IMDB sentiment classification.
- Use SHAP to analyze model decisions for IMDB sentiment classification.
